# Forest Edge Kart Club website

The static site for Forest Edge Kart Club: an owner-driver kart club racing under a Motorsport UK licence at Barton Stacey, off the A303.

## Theme

Light paddock and forest greens, with the racing look kept:

- **Surfaces:** off-white `#f7f9f6` pages, white cards, sage lines and section washes.
- **Greens:** pine `#1f3d2b` and hunter `#2d5a3d` for headings, buttons, the photo bands and the footer.
- **Motorsport details:** Semakin headlines (Archivo as fallback), IBM Plex Mono for times and countdowns, slanted photo panels with a kerb along the cut.
- **Signals:** club red for the logo, race days and the selected sector. Hi-vis amber still means *live* or *next on track*.

All colours are CSS variables at the top of `assets/css/main.css`. The header uses `assets/img/logo-light.png`, which is the club logo with its white circuit outline recoloured pine so it shows on the light header. The footer uses `assets/img/logo-white.webp` (PNG fallback `logo-white.png`), an all-white version of the logo on dark green.

## Fonts

Headings use **Semakin** (© Drizy Studio 2022), self-hosted at `assets/fonts/semakin-regular.otf`. The file has no licence text, and Drizy Studio fonts are usually free for personal use only, with a paid licence for commercial or web use. Keep a copy of the licence that covers this site. Body text is Barlow and timing figures are IBM Plex Mono, both under the SIL Open Font License.

## Deploying

Upload everything **except** `archive/` and `README.md` to the web root.

The stylesheet and script are linked with `?v=20261021-4`. When you change `main.css` or `main.js`, bump that value in every page and in `sw.js` (`SHELL`, plus the `CACHE` name). Otherwise the service worker, which serves styles and scripts cache-first, can keep showing visitors the old files.

## Rebuilding with build.py

`sw.js` says the site is generated by `build.py`, which isn't in this repo. If you rebuild from that source, carry these changes into it or they'll be overwritten:

- `assets/css/main.css` (the new theme) and `assets/img/logo-light.png`
- `assets/fonts/semakin-regular.otf`
- In every page's `<head>`: `theme-color` `#f7f9f6`, the three font `preload` links (Barlow 400, Barlow 600, Semakin), and the `?v=` on `fonts.css`, `main.css` and `main.js`
- Header logo `src` → `assets/img/logo-light.png`
- Home page button text "Come and practice"
- `site.webmanifest` colours and the `sw.js` `SHELL` list

`archive/placeholder-onepager/` holds an earlier placeholder design and can be deleted.
